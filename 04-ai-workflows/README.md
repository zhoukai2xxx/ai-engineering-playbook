# AI ワークフロー

AI に仕事を任せるときの「入力・出力・受け入れ」をここに集約する。

| 種類 | 場所 | 用途 |
|------|------|------|
| プロンプト | `prompts/` | 要件・設計・実装・レビュー・リファクタ |
| 出力契約 | `output-contracts/` | AI が必ず従う章立て |
| タスクカード | `task-templates/` | Phase を同じ粒度で分解する |
| 受け入れ | `acceptance-checklists/` | 次フェーズに進む前の確認 |
| アンチパターン | `anti-patterns/` | やってはいけない頼み方 |

## 原則

1. プロンプトは場当たりで作らない
2. 出力は必ず `output-contracts/` に合わせる
3. チェックリストを通らない成果物は次に進まない
4. コード変更の可否はタスクカードで人が指定する
