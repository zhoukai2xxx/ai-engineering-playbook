# AI プロンプト：開発タスク分解

## 使用場面

1 つの Phase を、段階的に実行できる小タスクへ分解します（Cursor Agent が順番に実行するため）。

## 入力（使用前に記入）

```
Phase 番号：
Phase 内容：（要件ドキュメントからコピー）
前提 Phase の完了内容：
技術スタック：Next.js + Prisma + PostgreSQL
```

## プロンプト

```
以下の Phase を 5〜10 個の「独立して実行できる小タスク」に分解してください。
各タスクは 30 分〜2 時間で完了できる粒度にしてください。

【Phase 内容】
（Phase の説明を貼り付け）

【完了済みの前提作業】
（前提 Phase の成果物を貼り付け）

【分解要件】
1. 各タスクは `04-ai-workflows/task-templates/task-card-template.md` の項目をすべて埋める
2. タスク間に明確な先後関係を付ける
3. 先にバックエンド/API、次にフロントページ
4. DB 変更タスクは最初に配置する
5. 「AI が直接コードを変更してよいか」は人が後でチェックするので、草案では「いいえ」にしてよい
6. 各タスクに Cursor Agent 用の指示文を含める

【出力形式】
task-card-template.md と同じ見出しで、タスクごとに 1 枚出力する。
```

## 次のステップ

タスク順に Cursor へ依頼する。コード変更はタスクカードで「はい」と人がチェックしてから Agent に渡す。
