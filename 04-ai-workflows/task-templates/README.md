# タスク分解の標準

Phase を進めるときは、必ず本ディレクトリのタスクカード形式で分解する。自分・同僚・Cursor が同じカードを読む。

## 使い方

1. `prompts/implementation/task-breakdown-prompt.md` で Phase を 5〜10 タスクに分解する
2. 各タスクを `task-card-template.md` に転記する
3. 「AI が直接コードを変更してよいか」を人がチェックする
4. Ask で方針確認 → Agent で実装（許可した場合のみ）
5. 受け入れ基準を満たしたら次のタスクへ

## 必須項目

各タスクカードは次を必ず含む。

| 項目 | 説明 |
|------|------|
| 目標 | 1 文で何を達成するか |
| 範囲 | やること / やらないこと |
| 入力資料 | 読むべきドキュメント・コードのパス |
| 成果物 | 作成・変更するファイル、API、画面 |
| やらないこと | スコープ外を明示し、AI の勝手な拡張を防ぐ |
| 受け入れ基準 | 完了判定のチェックリスト |
| リスク点 | 失敗しやすい点、権限・DB・互換性など |
| AI が直接コードを変更してよいか | はい / いいえ（いいえなら方案のみ） |
