# 学びの回収（経験のフィードバック）

標準は最初から完成しない。プロジェクトで使った結果を、本ディレクトリへ戻す。

## 各プロジェクトで必ず残すファイル

| ファイル | いつ書く | 何を書く |
|----------|----------|----------|
| `lessons-learned.md` | 随時（週 1 でも可） | その週に学んだこと |
| `adopted-patterns.md` | うまくいったと確認したとき | 今後も使うテンプレート・手順 |
| `mistakes-to-avoid.md` | つまずいた直後 | AI のブレ、手戻り、コミュニケーションの問題 |

## 回収する観点（毎回同じ質問）

- どのテンプレートが本当に役立ったか
- どのプロンプトが有効だったか
- どの AI 出力が最もブレやすいか
- どの工程は人の確認が必須か
- どのディレクトリ構成・命名が楽だったか

## タイミング

- 金曜 10 分：各ファイルに 2〜3 行追記
- Phase 完了時：整理し、本プレイブックへ反映する候補を決める
- プロジェクト完了時：`adopted-patterns.md` から標準へ昇格
